# Bollywood Cover Art Folder

Place your Bollywood album/movie cover art images here.

## Naming Convention

Name the file to match the song's `id` in `bollywoodTracks.ts`:
- Song id: `kuch-kuch-hota-hai` → Cover file: `kuch-kuch-hota-hai.jpg`
- Song id: `chaiyya-chaiyya` → Cover file: `chaiyya-chaiyya.jpg`

## Specs
- Format: JPG or PNG
- Recommended size: 500×500px or larger (square)

If no cover image is provided, a beautiful Bollywood-themed gradient fallback will be used automatically.
